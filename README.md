# 几猫国产 3A 大作 · V1

一个可以直接在浏览器中运行的 3D 第一人称射击小游戏。以失控的港区防御系统为背景，玩家扮演几猫突击小队成员，在集装箱堆场、仓库和码头之间穿行，切断三处上行中继，突破机械守卫的封锁，最终登船撤离。

项目采用单文件静态页面形式：HTML、CSS、JavaScript 与 Three.js 渲染代码均已内置在 `index.html` 中，无需安装依赖、构建工具或后端服务。

## 游戏特色

- **港区 3D 场景**：集装箱、起重机、仓库与码头，搭配雨水、锈迹和烟雾效果。
- **完整任务流程**：切断三处中继 → 应对逐步增强的敌方增援 → 抵达撤离艇。
- **两类机械敌人**：空中的机械飞鸥与地面的机械猎犬。
- **第一人称战斗**：射击、瞄准、换弹、近战、跳跃、冲刺与蹲伏。
- **中文界面**：任务提示、方向指示、无线电字幕和行动结算。
- **多种输入方式**：桌面键鼠及移动端触屏操作。
- **可调设置**：画质、鼠标灵敏度、视野和音量；设置保存在当前浏览器中。

## 本地运行

下载仓库后，直接使用支持 WebGL 2 的现代浏览器打开 `index.html`。

也可以通过 Python 启动本地静态服务器：

```bash
git clone https://github.com/h-pl/jimao-3a.git
cd jimao-3a
python3 -m http.server 8000
```

浏览器访问 <http://localhost:8000>，点击「开始行动」。

## 操作说明

| 操作 | 键位 |
| --- | --- |
| 移动 | W / A / S / D |
| 转动视角 | 鼠标 |
| 开火 / 瞄准 | 鼠标左键 / 右键 |
| 换弹 | R |
| 切断中继 | 靠近后按住 E |
| 跳跃 | Space |
| 冲刺 | Shift |
| 蹲伏 | C 或 Ctrl |
| 近战 | F |
| 暂停 | Esc 或 P |

移动端：在屏幕左侧滑动控制移动，在右侧拖动调整视角，使用屏幕按钮开火、瞄准、换弹、跳跃和交互。将移动摇杆推至最前方可以冲刺。

## 静态部署

将 `index.html` 放到静态网站的根目录即可运行，无需构建命令。

如需启用 GitHub Pages，在仓库 **Settings → Pages** 中选择 **Deploy from a branch**，分支选择 **main**，目录选择 **/ (root)**，保存后等待发布。
