# 几猫国产 3A 大作

**港区突击 · 切断中继 · 登艇撤离**

一个打开浏览器就能玩的 3D 第一人称射击小游戏。单文件运行，支持电脑键鼠和手机触屏。

### [🎮 立即在线试玩](https://h-pl.github.io/jimao-3a/)

进入页面，点击「开始行动」。无需下载、安装或注册。

## 任务背景

港区防御系统失控，机械守卫封锁了泊位。你将作为几猫突击小队的一员，独自穿过集装箱堆场、仓库与码头，解除封锁并撤离。

1. **寻找中继**：跟随任务标记，找到港区内的三处上行中继。
2. **切断连接**：靠近中继并持续交互，同时应对机械飞鸥和机械猎犬的增援。
3. **登艇撤离**：全部中继断开后，前往码头南端的撤离艇，完成行动。

## 游戏特色

- **3D 港区场景**：集装箱、起重机、仓库和码头，搭配雨水、锈迹与烟雾效果。
- **第一人称战斗**：射击、瞄准、换弹、近战，以及跳跃、冲刺和蹲伏。
- **逐步升级的遭遇战**：切断中继触发敌方增援，撤离阶段继续应对追击。
- **中文任务界面**：方向指示、任务标记、无线电字幕与行动结算。
- **画面与操作设置**：可调画质、灵敏度、视野和音量，设置保存在当前浏览器中。

## 操作说明

### 电脑键鼠

| 操作 | 键位 |
| --- | --- |
| 移动 | W / A / S / D |
| 转动视角 | 鼠标 |
| 开火 / 瞄准 | 鼠标左键 / 右键 |
| 换弹 | R |
| 切断中继 | 靠近后按住 E |
| 跳跃 | Space |
| 冲刺 | Shift |
| 蹲伏 | C 或 Ctrl |
| 近战 | F |
| 暂停 | Esc 或 P |

### 手机触屏

左侧滑动控制移动，右侧拖动调整视角。屏幕按钮支持开火、瞄准、换弹、跳跃和交互；将移动摇杆推至最前方即可冲刺。

## 本地运行

下载仓库，使用支持 **WebGL 2** 的浏览器打开 `index.html` 即可游玩。也可以通过本地静态服务器运行：

```bash
git clone https://github.com/h-pl/jimao-3a.git
cd jimao-3a
python3 -m http.server 8000
```

打开 [http://localhost:8000](http://localhost:8000)，点击「开始行动」。运行不流畅时，可在游戏设置中降低画质。
